# Aplikasi Bimbingan Belajar & Tutor (Bimbel Online)

## Deskripsi
Aplikasi CLI berbasis Python yang menerapkan konsep OOP:
Abstract Class, Inheritance, Polymorphism, Encapsulation,
Custom Exception, Design Pattern (Facade & Strategy), dan penyimpanan Pickle.

## Cara Menjalankan
1. Pastikan Python 3.10+ terinstall.
2. Clone repo ini: `git clone <url>`
3. Masuk folder: `cd UTS_PBO`
4. Jalankan: `python main.py`

## Struktur Folder
- `models/` — Class User, Siswa, Tutor, Sesi, PengelolaAplikasi
- `services/` — Logika bisnis (registrasi, booking, payment)
- `utils/` — Validator, input helper, iterator
